# Lung Segmentation

Deep learning–based lung segmentation developed as part of a university project in medical imaging and deep learning.

This repository contains a trained segmentation model and a Python application for running inference on medical images.

---

## Project Description

The goal of this project was to implement and deploy a neural network for automatic lung segmentation.

The repository includes:

- A trained model (`best_metric_model.pth`)
- A Python inference script (`lung_segmentation_app.py`)
- A requirements file for reproducibility

The segmentation pipeline consists of:

1. Image loading
2. Preprocessing
3. Model inference
4. Mask generation
